# Systems & Services

Operating systems, web servers, DNS services, and security tools for infrastructure.

---

## Operating Systems

| System | Description |
|--------|-------------|
| [Slackware](http://www.slackware.com/) | The most "Unix-like" Linux distribution |
| [OpenBSD](https://www.openbsd.org/) | Multi-platform 4.4BSD-based UNIX-like OS |
| [HardenedBSD](https://hardenedbsd.org/) | Innovative exploit mitigation and security |
| [Kali Linux](https://www.kali.org/) | Penetration testing and ethical hacking |
| [Parrot Security OS](https://www.parrotsec.org/) | Cyber security GNU/Linux environment |
| [Backbox Linux](https://www.backbox.org/) | Security assessment Ubuntu-based distro |
| [BlackArch](https://blackarch.org/) | Arch Linux-based penetration testing |
| [Security Onion](https://securityonion.net/) | Intrusion detection and log management |
| [Tails](https://tails.boum.org/) | Privacy and anonymity live system |
| [Qubes OS](https://www.qubes-os.org) | Security-oriented OS with Xen virtualization |

## HTTP(s) Services

| Service | Description |
|---------|-------------|
| [Varnish Cache](https://varnish-cache.org/) | HTTP accelerator for dynamic web sites |
| [Nginx](https://nginx.org/) | Open source web and reverse proxy server |
| [OpenResty](https://openresty.org/en/) | Dynamic web platform based on NGINX |
| [Tengine](https://github.com/alibaba/tengine) | Nginx distribution with advanced features |
| [Caddy Server](https://caddyserver.com/) | HTTP/2-enabled web server with HTTPS by default |
| [HAProxy](https://www.haproxy.org/) | High performance TCP/HTTP load balancer |
