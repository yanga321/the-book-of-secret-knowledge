# Web Tools

Online tools and services for security testing, DNS analysis, SSL verification, and more.

---

## Browser Testing

- [SSL/TLS Capabilities](https://www.ssllabs.com/ssltest/viewMyClient.html) - Test your browser's SSL implementation
- [Can I use](https://caniuse.com/) - Browser support tables for front-end technologies
- [Panopticlick 3.0](https://panopticlick.eff.org/) - Browser tracking safety test
- [Privacy Analyzer](https://privacy.net/analyzer/) - See what data is exposed
- [Web Browser Security](https://browserleaks.com/) - Browser fingerprinting info

## SSL/Security

- [SSLLabs Server Test](https://www.ssllabs.com/ssltest/) - Deep analysis of SSL web server config
- [ImmuniWeb SSLScan](https://www.immuniweb.com/ssl/) - Test SSL/TLS (PCI DSS, HIPAA, NIST)
- [CryptCheck](https://cryptcheck.fr/) - Test TLS server configuration
- [urlscan.io](https://urlscan.io/) - Scan and analyse websites
- [CSP Evaluator](https://csp-evaluator.withgoogle.com/) - Check Content Security Policy
- [badssl.com](https://badssl.com/) - Test clients against bad SSL configs
- [crt.sh](https://crt.sh/) - Certificate Transparency search

## DNS Tools

- [ViewDNS](http://viewdns.info/) - Free DNS related tools
- [DNSdumpster](https://dnsdumpster.com/) - DNS recon & research
- [What's My DNS](https://whatsmydns.com) - DNS propagation checking
- [intoDNS](https://intodns.com/) - DNS and mail server health checker
- [dnssec-debugger](https://dnssec-debugger.verisignlabs.com/) - DNSSEC validator

## HTTP Headers & Linters

- [Security Headers](https://securityheaders.com/) - Analyse HTTP response headers
- [Observatory by Mozilla](https://observatory.mozilla.org/) - Website analysis tools
- [webhint](https://webhint.io/) - Linting tool for accessibility, speed, security

## Mail Tools

- [MX Toolbox](https://mxtoolbox.com/SuperTool.aspx) - MX record, DNS, blacklist diagnostics
- [DKIM Validator](https://dkimvalidator.com/) - Mail authentication checks

## Encoders/Decoders & Regex

- [URL Encode/Decode](https://www.url-encode-decode.com/) - Encode or decode strings
- [Regex101](https://regex101.com/) - Online regex tester and debugger
- [CyberChef](https://gchq.github.io/CyberChef/) - Web app for encryption, encoding, compression

## Network Tools

- [Netcraft](https://toolbar.netcraft.com/site_report) - Detailed site reports
- [RIPE NCC Atlas](https://atlas.ripe.net/) - Global Internet measurement platform
- [Robtex](https://www.robtex.com/) - IP, domain, hostname information
- [Security Trails](https://securitytrails.com/) - Security APIs
- [VirusTotal](https://www.virustotal.com/gui/home/upload) - Analyse suspicious files and URLs

## Mass Scanners (Search Engines)

- [Censys](https://censys.io/) - Discover and monitor devices
- [Shodan](https://www.shodan.io/) - Search engine for Internet-connected devices
- [ZoomEye](https://www.zoomeye.org/) - Cyberspace search engine
- [FOFA](https://fofa.so/) - Cyberspace search engine
- [binaryedge](https://app.binaryedge.io/) - Internet scanning and threat intelligence
- [OSINT Framework](https://osintframework.com/) - Free OSINT tools and resources

## Performance Testing

- [GTmetrix](https://gtmetrix.com/) - Analyze site speed
- [Pingdom Tools](https://tools.pingdom.com/) - Speed analysis worldwide
- [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights/) - Google's speed analysis
- [Lighthouse](https://github.com/GoogleChrome/lighthouse) - Automated auditing and best practices

## CVE/Exploits Databases

- [CVE Mitre](https://cve.mitre.org/) - Publicly known vulnerabilities
- [Exploit DB](https://www.exploit-db.com/) - Archive of public exploits
- [sploitus](https://sploitus.com/) - Exploit and tools database
- [cveapi](https://cveapi.com/) - Free API for CVE data
